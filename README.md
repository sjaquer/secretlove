# 💕 Secret Love - Amor Secreto

Una página web romántica interactiva creada con amor para celebrar momentos especiales.

## ✨ Características

- 🌊 **Fondo de Acuario Interactivo**: Hermoso fondo oceánico con peces nadando, corales balanceándose, burbujas flotantes y efecto parallax suave al mover el mouse
- ⏰ **Cuenta Regresiva**: Contador elegante hasta el 14 de febrero de 2026 (Día de San Valentín)
- 🔐 **Códigos Secretos**: Sistema de códigos que desbloquean diferentes experiencias románticas
- 📱 **Diseño Responsivo**: Optimizado para móviles, tablets y escritorio
- 🎨 **Tema Romántico**: Paleta de colores en tonos rosa, rojo y blanco

## 🗝️ Códigos Secretos

| Código | Página | Descripción |
|--------|--------|-------------|
| `OTOÑO` | /story | Historia interactiva generada con IA |
| `AMOR` | /puzzle | Rompecabezas de una imagen especial |
| `HORTENSIA` | /card | Tarjeta de amor personalizada |
| `CANCION` | /canciones | Playlist de canciones especiales |
| `TAMMV` | /video | Video especial (próximamente) |
| `CARTA` | - | Carta de amor (próximamente) |

## 🛠️ Tecnologías

- **Next.js 14** - Framework de React con App Router
- **TypeScript** - Tipado estático
- **Tailwind CSS** - Estilos utilitarios
- **Shadcn/ui** - Componentes de UI modernos
- **Lucide Icons** - Iconografía elegante
- **Genkit AI** - Generación de historias con IA

## 🚀 Comenzar

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Construir para producción
npm run build
```

## 📁 Estructura del Proyecto

```
src/
├── app/              # Páginas de Next.js
│   ├── page.tsx      # Página principal con CodeGate
│   ├── story/        # Historia interactiva
│   ├── puzzle/       # Rompecabezas
│   ├── card/         # Tarjeta de amor
│   ├── canciones/    # Playlist de Spotify
│   └── video/        # Video especial
├── components/       # Componentes reutilizables
│   ├── AquariumBackground.tsx  # Fondo oceánico animado
│   ├── CodeGate.tsx            # Puerta de códigos
│   ├── Countdown.tsx           # Cuenta regresiva
│   └── ui/                     # Componentes de UI base
├── ai/               # Flujos de IA con Genkit
└── lib/              # Utilidades y códigos
```
